## Задача

Владелец: «посмотри проект. реанимируй его. настрой для работы с агентами.
возьми примеры настроек у соседей».

## Что сделано

**Тулчейн.** Пол по соседям: `sdk: ^3.6.0`, `flutter: ">=3.27.0"`, fvm
на 3.27.0. `analysis_options.yaml` — копия navigation_node (строгий набор
поверх `flutter_lints` 5) с двумя правками: убраны строки, специфичные для
navigation_node, и у `require_trailing_commas` записано, почему он живёт только
до языка 3.7. `pubspec.yaml` получил `repository`, `issue_tracker`, `topics`
и `screenshots`. Корневой `pubspec.lock` снят с учёта.

**Тесты до правок.** Сначала тесты, потом чистка: 36 снимков формы и отступов
`BubbleClipper` (`test/bubble_clipper_test.dart`) и 14 тестов виджета
(`test/bubble_test.dart`) написаны и прогнаны на нетронутом `lib/`. Снимки
сняты пробником с исходного кода, а не выведены: каждая картинка — путь
клиппера 32×20, проверенный `Path.contains` по центрам пикселей. Варианты: все
семь `BubbleNip`, `showNip: false`, `stick` с обеих сторон, острый кончик,
`nipOffset`, широкий хвостик со скруглением, радиус больше пузыря.

**Чистка `lib/`.** 122 замечания строгого набора, все механические: dartdoc
на каждый публичный член, `super.key`, явный `case BubbleNip.no` вместо
`default`, лишние `break`, висячие запятые, `library;` вместо
`library bubble;`, лишний импорт `dart:ui`, `!` на ненулевом. Формулы клиппера
не тронуты. Все 50 тестов зелёные и после чистки.

**Пример.** Платформенные папки сгенерированы `flutter create` 3.27.0
в отдельном каталоге и перенесены: android, ios, web, windows — как было, плюс
macos для запуска на машине владельца. `publish_to: none`, url_launcher
`^6.3.1` с `launchUrl`, свой `analysis_options.yaml` по образцу
navigation_node, смоук-тест вместо «счётчика», `example/README.md` вместо
шаблона Flutter. `flutter build macos --debug` на 3.27.0 собирает приложение.

**Публикация.** `.pubignore` по образцу navigation_node; сверх него — все
скриншоты, кроме `screenshots/example.png`: README берёт их с GitHub
по абсолютным ссылкам, а в архиве они весили 644 КБ при 36 КБ `lib/`. Архив
теперь 84 КБ.

**CI.** `.github/workflows/ci.yml` — те же проверки, что в `AGENTS.md`, на двух
ногах: 3.27.0 и stable. Actions запинены по SHA, как в logger_builder
и ansi_escape_codes, `dependabot.yml` их двигает; major-обновление
`flutter_lints` в нём заглушено — 6.0.0 требует SDK `^3.8.0`.

**Регламент.** `CLAUDE.md` → `@AGENTS.md`; `AGENTS.md` собран
из navigation_node (порядок восстановления, handoff, бэклог, records,
проверки), ansi_escape_codes (публикация, «чего не делать»)
и flutter_team_logger (записи вместо путей скиллов). `docs/handoff.md`,
`docs/backlog.md` (пустой, для владельца), `docs/architecture.md`,
`docs/ru/check.sh` и `stamp.sh` из navigation_node, русские зеркала обоих
README.

## Решения, принятые по умолчанию

Каждое — то, что делают соседи; каждое владелец может развернуть.

- **Публичный API и поведение не менялись**, даже где найдены дефекты: пакетом
  пользуются, а регламент соседей отдаёт такие правки владельцу. Дефекты
  записаны в handoff (Д1, Д2) с выводом пробников.
- **Версия не бампнута**, всё лежит в `## Unreleased`.
- **Коммиты и push — только по слову владельца.** Коммитить он разрешил тем же
  днём, push — нет.
- **Ветка `master` оставлена**, хотя у соседей `main`.
- **Правила push и GitHub в `AGENTS.md` строже, чем у ansi_escape_codes**: там
  push разрешён словом владельца от 2026-08-12, здесь такого слова нет.
- **`test/` публикуется** (у navigation_node исключён): 32 КБ против 36 КБ
  `lib/`, исключать незачем.
