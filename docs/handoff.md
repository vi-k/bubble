1. коммит `Release 1.3.0`: `version: 1.3.0` в `pubspec.yaml`, в `CHANGELOG.md`
   заголовок `## 1.3.0 (YYYY-MM-DD)` вместо `## Unreleased`. `CHANGELOG.md`
   хранится с CRLF: Python `read_text`/`write_text` переводит весь файл в LF,
   после правки — `git ls-files --eol CHANGELOG.md`;
2. тег `1.3.0`, без `v`;
3. `git push origin main 1.3.0` — уйдут и все коммиты, накопленные после
   прошлого push. CI на них не гонялся, их проверки — локальные (раздел
   «Проверки»);
4. `fvm dart pub publish`. Файл учётных данных pub.dev на машине есть,
   действует ли вход — видно только при публикации.
